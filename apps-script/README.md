# Скрипт Google Таблицы

Чтобы статусы с сайта («Не взяли», «Перезвонить», «Интерес», «Отказ»), заметки и время звонка
записывались в таблицу и были видны всем, а сама таблица выглядела аккуратно.

## Установка (один раз, ~5 минут)

1. Откройте Google Таблицу → **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` на [Code.gs](Code.gs) → 💾 Сохранить.
   (Если в старом скрипте было что-то своё, кроме чтения/записи для сайта, — сохраните его копию.)
3. Выберите функцию **formatSheet** → **▶ Выполнить** → разрешите доступ.
   Таблица получит тёмную шапку, зебру, ширину колонок, выпадающий список статусов с цветами,
   фильтр; служебные колонки key / phone_1–3 скроются. Данные не меняются.
4. **Начать развёртывание → Управление развёртываниями** → ✏️ → Версия: **Новая версия** → **Развернуть**.
   Ссылка `/exec` остаётся прежней. Доступ: «Выполнять от имени: я», «Кто имеет доступ: все».

## Что пишется в таблицу

| колонка     | что                                   |
|-------------|----------------------------------------|
| результат   | статус из выпадающего списка          |
| заметка     | ЛПР, время, что сказали               |
| звонок      | когда нажали «Позвонить»               |
| обновлено   | когда последний раз меняли строку      |

Статус можно менять и прямо в таблице — сайт подхватит при обновлении.
